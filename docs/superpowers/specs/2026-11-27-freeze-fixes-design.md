# 2차 동결 전 고칠 것: 근거 N개 숫자, 세탁기·건조기 아이콘 (짧은 설계)

- 날짜: 2026-11-27
- 상태: 확정(사용자 승인 2026-11-27)
- 관련: `docs/평가/phase2-mutual-test.md` 결과 D 2번·4번과 "근거 N개 재현", 결정기록 024(글꼴·아이콘 라이선스), `docs/design/디자인-가이드.md` 타일 항목, 노션 "펴봄 QA 모음"(근거 N개, 건조기 아이콘)
- 크기: 작은 변경 두 개, PR 하나

## 왜

- 상호 테스트에서 D가 말로 준 의견 두 개를 코드 동결(2026-11-30 밤) 전에 고친다
  - 4번: 이전 답 줄의 "근거 N개"가 질문할 때 본 근거 카드 수와 다르다. 재현 판정 1(줄은 인용 수, 카드는 묶음 수). 문구 수준이라 동결 전에 고친다(사용자 결정 2026-11-27)
  - 2번: 건조기 아이콘이 세탁기 아이콘과 구분이 안 된다. 정리 기준에 따로 없는 경우라 2차 안에 바꾼다(명시적 예외, 사용자 결정 2026-11-26)

## 목표

1. 이전 답 줄의 숫자가 그 답을 펼쳤을 때 보이는 근거 카드 수와 같다
2. 카테고리 타일에서 세탁기와 건조기를 한눈에 구분할 수 있다

## 하지 않을 것

- 근거 카드, 최신 답의 "근거 보기 · …" 줄(`evidenceLabel`), "드릴까요?" 버튼은 바꾸지 않는다
- 질문·답변 코드(`app/answer/`)는 손대지 않는다(계획 Global 1)
- 에어컨·"더 추가 예정" 타일과 다른 화면의 아이콘(Tabler)은 바꾸지 않는다
- 상호 테스트에서 기록만 하기로 한 것(다크모드, 이모지 글자 수)은 하지 않는다

## 실패로 볼 것

- 숫자를 바꾸다가 근거 카드의 내용·순서·개수가 바뀐다
- 아이콘 파일만 넣고 라이선스 원문·출처 기록이 빠진다

## 접근

### 근거 N개

- 고름: **묶음 수로 센다.** 근거 카드를 만드는 `groupCitations`(설명서는 쪽별, 가이드는 문서별)를 그대로 다시 쓴다(사용자 결정 2026-11-27)
- 고르지 않음: 줄에 쪽 번호까지 쓰기(`evidenceLabel` 재사용). 문구가 길어지고 화면 구조를 바꾸는 쪽에 가깝다
- 고르지 않음: 줄은 인용 수 그대로 두고 카드를 인용마다 나누기. 근거 카드 구조가 바뀐다

### 세탁기·건조기 아이콘 (시안 다섯 번, 2026-11-27)

- 지금 묶음(Tabler 3.19.0) 그대로: 바람(`wind`), 옷걸이(`hanger`) → 사용자가 지금 모양과 바람을 합친 그림을 원함
- 직접 그려 합치기: 네모·동그라미 + 바람, 김 나는 기계, 둥근 문 + 바람, 까만 문 + 하얀 김, 옷 + 김 → 사용자 판단: 모양이 어색하고 건조기로 알아보기 어려움
- 고름: **MDI(`@mdi/svg` 7.4.47, Pictogrammers)의 `washing-machine`·`tumble-dryer`를 세탁기·건조기 타일에 고치지 않고 쓴다**(사용자 결정 2026-11-27, 범위 "세탁기·건조기")
  - 아이콘 묶음 8개(Tabler 3.19.0·3.53.0, lucide, Phosphor, iconoir, Remix, Material Symbols, Fluent, MDI)의 파일 목록 중 건조기 그림이 있는 것은 MDI 하나였다(채팅 Claude 확인 2026-11-27)
  - 세탁기도 같이 바꾸는 이유: 두 그림이 같은 묶음이라 나란히 있어도 어울리고, 물(세탁기)과 김(건조기)으로 차이가 보인다
  - 에어컨은 바꾸지 않는다: MDI 에어컨은 선풍기 모양에 영어 "A/C" 글자가 있다
  - 알고 고른 것: MDI는 면을 채운 그림이라 선 그림인 에어컨·"더 추가 예정" 타일과 모양 방식이 다르다

## 정한 것 (사용자 결정)

1. 이전 답 줄: `이전 답 · 근거 N개`의 N은 `groupCitations(citations).length`. 0이면 지금처럼 `이전 답 · 근거 없음`. 문구는 그대로
2. 세탁기 타일 = MDI `washing-machine.svg`, 건조기 타일 = MDI `tumble-dryer.svg`. 파일 내용은 고치지 않는다
