# 펴봄 사전 설문 — 자취생 가전 사용 실태

> 저장 위치: `docs/설문-문항.md` · 생성 스크립트: `docs/create_pyeobom_survey.gs` · 결과 정리: `docs/설문-결과.md` · 근거: 기획서 2.2
> 목표 응답 시간 3분, 목표 응답 수 5~10명(리뷰 그룹·동기)
> **설계 원칙**: 세탁기·에어컨은 "주로 쓰는 한 대"만 묻는다 → 응답 1건 = 응답 시트 1행이라 가공이 쉽다. 두 번째 가전은 Q20 자유 입력으로만 받는다.

---

## 첫 화면 안내문

> 펴봄(가전 설명서 Q&A 서비스) 1차 프로젝트를 위한 3분 설문입니다.
> 이름·연락처·이메일은 받지 않으며, 결과는 집계해서 프로젝트 문서와 발표에만 씁니다.
> 세탁기·에어컨은 지금 주로 쓰는 한 대를 기준으로 답해 주세요.
> 모델명은 제품에 붙은 라벨에서 확인할 수 있어요(위치는 제품마다 달라요). 모르면 비워 두세요.

## 흐름

```
섹션1 기본(Q01, Q02 세탁기 있나요?) ─ 있음 → 섹션2 세탁기(Q03~Q06) ─┐
                                    └ 없음 ─────────────────────────┤
섹션3 에어컨 있나요?(Q07) ─ 있음 → 섹션4 에어컨(Q08~Q11) ─┐          ↓
                          └ 없음 ─────────────────────────┤
섹션5 막힌 적 있나요?(Q12) ─ 예 → 섹션6 경험 상세(Q13~Q17) ─┐
                            └ 아니요 ─────────────────────┤
섹션7 서비스 의향(Q18~Q21) → 제출
```

---

## 문항

문항 제목 앞의 `Qnn [분류]`는 응답 시트의 열 이름이 되므로 그대로 둔다(분석할 때 열을 찾기 쉽다).

**섹션 1. 기본**
- **Q01 [기본] 지금 사는 곳** (객관식, 필수) — 원룸·오피스텔(옵션 가전 있음) / 원룸·오피스텔(옵션 가전 없음) / 셰어하우스·기숙사 / 본가·가족과 거주 / 기타(직접 입력)
- **Q02 [세탁기] 지금 쓰는 세탁기가 있나요?** (객관식, 필수) — 있음 → 섹션 2 / 없음 → 섹션 3

**섹션 2. 세탁기** (주로 쓰는 한 대)
- **Q03 [세탁기] 브랜드** (객관식, 필수) — 삼성 / LG / 모름 / 기타(직접 입력)
- **Q04 [세탁기] 종류** (객관식, 필수) — 통돌이 / 드럼 / 세탁건조기 일체형 / 세탁조 2개 결합형 / 모름
  - 도움말: 통돌이 = 위에서 여는 형태, 드럼 = 앞에서 여는 형태, 세탁건조기 일체형 = 한 대로 세탁과 건조
- **Q05 [세탁기] 모델명** (단답, 선택)
- **Q06 [세탁기] 설명서 보유** (객관식, 필수) — 종이 설명서 있음 / PDF·앱으로 본 적 있음 / 없음 / 모름

**섹션 3. 에어컨 여부**
- **Q07 [에어컨] 지금 쓰는 에어컨이 있나요?** (객관식, 필수) — 있음 → 섹션 4 / 없음 → 섹션 5

**섹션 4. 에어컨** (주로 쓰는 한 대)
- **Q08 [에어컨] 브랜드** (객관식, 필수) — 삼성 / LG / 캐리어 / 위니아 / 파세코 / 위닉스 / 모름 / 기타(직접 입력)
- **Q09 [에어컨] 종류** (객관식, 필수) — 벽걸이 / 스탠드 / 창문형 / 천장형(시스템) / 이동식 / 모름
- **Q10 [에어컨] 모델명** (단답, 선택)
- **Q11 [에어컨] 설명서 보유** (객관식, 필수) — 종이 설명서 있음 / PDF·앱으로 본 적 있음 / 없음 / 모름

**섹션 5. 막혔던 경험 여부**
- **Q12 [경험] 최근 6개월 안에 세탁기나 에어컨을 쓰다가 막힌 적이 있나요?** (객관식, 필수) — 예 → 섹션 6 / 아니요 → 섹션 7

**섹션 6. 경험 상세**
- **Q13 [경험] 어떤 상황이었나요?** (체크박스, 필수) — 에러 코드가 떴다 / 기능·사용법을 몰랐다(예약·통세척·모드 등) / 청소·관리 방법을 몰랐다(필터 등) / 고장인지 아닌지 몰랐다 / 기타
- **Q14 [경험] 어떻게 해결하려고 했나요?** (체크박스, 필수) — 인터넷 검색(포털·블로그·영상) / 제조사 사이트·앱 / 종이 설명서 / 고객센터·AS 전화 / 집주인·관리인 문의 / AI 챗봇(ChatGPT 등) / 포기했다 / 기타
- **Q15 [경험] 해결까지 걸린 시간** (객관식, 필수) — 5분 이내 / 5~15분 / 15~30분 / 30분 이상 / 해결 못 함
- **Q16 [경험] 찾은 정보가 다른 모델 이야기여서 헷갈린 적이 있나요?** (객관식, 필수) — 있다 / 없다 / 잘 모르겠다
- **Q17 [경험] 가장 불편했던 점 한 줄** (단답, 선택)

**섹션 7. 서비스 의향**
- **Q18 [의향] 근거(쪽·출처)와 함께 답해 주는 서비스를 써 볼 생각** (1~5 배율, 필수) — 1 전혀 없음 ~ 5 꼭 써 보고 싶음
- **Q19 [의향] 가장 중요한 것** (객관식, 필수) — 정확한 답 / 빠른 답 / 근거(쪽·출처) 표시 / 쉬운 말 / 기타
- **Q20 [기타] 다른 세탁기·에어컨이 더 있거나 하고 싶은 말** (장문, 선택)
- **Q21 [테스트] 10/30~11/2 중 10분 사용자 테스트 참여** (객관식, 필수) — 예 / 아니요 ("예"라면 캠프 채널에서 따로 알려 달라고 안내, 연락처는 받지 않음)

## 문항과 가설 연결 (기획서 2.1)

| 가설 | 확인 문항 | 판단 기준(예시) |
| --- | --- | --- |
| 옵션 가전 사용자는 설명서가 없는 경우가 많다 | Q01, Q06, Q11 | "없음" 비율 |
| 집 안에 브랜드가 섞여 있다 | Q03, Q08 (같은 응답자) | 세탁기와 에어컨 브랜드가 다른 비율 |
| 원룸 세탁기 종류 분포 | Q04 | 종류별 비율 → 지원 모델 선택의 근거 |
| 검색하면 다른 모델 정보가 섞여 헷갈린다 | Q16 | "있다" 비율 |
| 해결에 시간이 걸린다 | Q15 | 15분 이상 + 해결 못 함 비율 → 사용자 테스트 비교의 기준선 |
| 이미 AI 챗봇으로 해결하고 있다(경쟁 확인) | Q14 | "AI 챗봇" 선택 비율 → 차별점 설명에 사용 |

응답이 적으면(5명 안팎) 비율보다 **실제 응답 사례**를 중심으로 쓰고, 일반화하지 않는다고 결과 문서에 밝힌다.

## 데이터 가공 메모

- **응답 1건 = 1행**: 세탁기·에어컨을 한 대씩만 물어서 열이 고정된다. 열 이름은 문항 제목(`Q03 [세탁기] 브랜드` 등)이다.
- **빈칸의 의미**: 세탁기가 "없음"이면 Q03~Q06이 비어 있다. 경험이 "아니요"면 Q13~Q17이 비어 있다. 비율을 낼 때는 **분모를 해당 문항에 답한 사람으로** 잡는다.
- **체크박스(Q13·Q14)**: 여러 개를 고르면 한 칸에 `, `(쉼표+공백)로 이어져 저장된다. 그래서 선택지 글자에 쉼표를 쓰지 않았다(가운뎃점 `·` 사용). 다만 "기타"에 응답자가 직접 쓴 글에는 쉼표가 들어갈 수 있으니, 나눌 때 기타 값을 따로 확인한다.
- **원본 응답 시트는 저장소에 올리지 않는다.** 집계 결과만 `docs/설문-결과.md`에 옮긴다.

## 생성 후 확인

1. 폼 [설정] 탭에서 이메일 수집이 꺼져 있는지, 로그인을 요구하는 설정이 꺼져 있는지 확인한다.
2. 미리보기로 "있음/예" 경로와 "없음/아니요" 경로를 각각 한 번씩 응답해 섹션 이동을 확인한다.
3. 시험 응답은 [응답] 탭과 응답 시트에서 모두 지운 뒤 배포한다.
