## 작업 B: 검색 실험 도구와 운영 검색 기준값 (M0, 1차 30문항, 2026-11-10)

- **도구:** `python -m measure.search_eval <질문 CSV> --label <이름>`(`measure/search_eval.py`). 답변 AI 없이 검색만 한다.
  - 입력 CSV 열: `id, model_id, question, expected_ref`(여러 개면 `|`). 기대 근거가 없는 행(함정)은 뺀다.
  - 처리: 운영과 같은 개인정보 가리기 → 질문 변형 함수(기본은 그대로, 검색 개선 실험이 끼울 자리) → 임베딩 → 모델 필터 벡터 검색 상위 20개 → 진단 규칙. 진단 규칙은 운영과 같은 함수(`needs_diagnostic`)를 쓴다.
  - 출력: 정답 조각 순위(20위 밖은 "없음"), 1·3·5위 안 적중률, 평균 역순위(1/순위의 평균, 20위 밖은 0), "5위 안 또는 진단 안내 쪽"(답변 AI에 실제로 넘어가는지). 결과 CSV(근거 표기만)와 `.settings.json`은 `measure/out/`에 둔다. 운영 기본값과 설정이 다르면 실행하지 않는다.
