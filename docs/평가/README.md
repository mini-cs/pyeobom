# 평가용 테스트 질문

## 고정 선언

- **2026-10-28 고정.** 이후 `evaluation/questions.csv`를 바꿀 때는 아래 "변경 기록"에 날짜·바꾼 행·이유를 적는다.
- 고정하는 이유: v1 → v2 개선을 같은 질문으로 비교해야 수치(정답률·근거 적중률·환각률·응답 시간)가 의미를 가진다(기획서 6.1).

## 파일

| 파일 | 역할 |
|---|---|
| `evaluation/questions.csv` | 평가에 쓰는 정본. 열은 `id, model_id, question, expected_keywords, expected_ref, type, expected_found` |
| `docs/평가/테스트질문-작성표.csv` | 작성할 때 쓴 원본 표. 작성 힌트와 대조 메모가 들어 있고, 기록으로 남긴다 |

- `model_id`는 `data/models.json`의 `id`다(작성표의 "모델" 열을 바꿨다).
- `expected_keywords`와 `expected_ref`는 `|`로 나눈다.
  - `expected_ref`의 `|`는 **여러 인정 근거**다. 하나라도 맞으면 근거 적중으로 본다.
  - 설명서는 `manual:<쪽>`, 가이드는 `guide:<doc_id>`로 적는다.
- 형식 검증은 `tests/evaluation/test_questions_csv.py`가 맡는다.
  - 검사 항목: 30행, 허용 유형, 함정 개수, 근거 표기, 모델 id
  - guide 근거는 `data/documents.json`이 생기기 전까지 `data/guides/`의 저장 파일 이름과 대조한다.

## 어떻게 만들었나

- **AI가 한 일:** 질문 초안, 근거 후보, 1차 대조는 AI(Claude)가 설명서와 공식 가이드를 읽고 수행했다. 1차 대조는 근거 쪽에 핵심 단어가 있는지, 함정 질문의 답이 설명서 전체에 없는지 확인하는 일이다.
- **사람이 한 일:** 채점 기준이 필요한 행(q03·q13·q23·q24)은 사람이 직접 확인했다.
  - q03: 세제 정량 표 읽기, 정답 "40"(ml)
  - q13: 이불 코스 최대 용량 "4.0" kg. 소수점이 빠지는 추출 문제를 이 확인에서 발견했다(결정기록 016 수정).
  - q23: 에어컨 코드가 있는 경우(CH05 → 공용 가이드)
  - q24: 에어컨 코드가 없는 경우(CH10 → "없다"고 밝히고 스마트 진단 안내)
- **고정 직전 확인 (2026-10-28, Claude Code):** 답이 있는 25행의 핵심 단어가 적어 둔 근거 쪽이나 가이드 본문에 들어 있는지 pypdfium2 추출 글자로 다시 대조했다. 25행 모두 맞았다.
