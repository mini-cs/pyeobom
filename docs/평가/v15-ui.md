### 성공 기준 (테스트 전 확정, N = 카드 시도 수)

1. **과제 해결:** "답을 찾았다(예)"가 N의 3분의 2 이상
2. **답 정확:** 캡처 사람 판정 정답 + 부분 정답이 3분의 2 이상, 환각 0
   - (보충 2026-11-12 사용자 결정, 테스트 전) 정답 + 부분 정답 3분의 2 이상은 **카드의 첫 답**으로 센다(분모 N). 환각 0은 받은 **모든 답**(첫 답 + 이어 물은 답)을 원문과 대조해 확인한다. 이어 물은 답은 미리 정한 기대 근거가 없으므로 환각 여부만 원문으로 본다
3. **입력창 찾기:** 설문 ① "못 찾음" 0명
4. **이어서 묻기:** 이어 물은 카드 중 3분의 2 이상 "알아들었다"
5. **믿음:** 설문 ② 평균 4점 이상
