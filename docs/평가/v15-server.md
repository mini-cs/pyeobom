**D 규칙 (코드로, `measure/compare_rewrite.py`의 `needs_rewrite`)** — 하나라도 맞으면 바꾼다

2. 생략 끝말: `도요?`·`땐요?`·`때는요?`·`면요?`·`은요?`·`는요?`로 끝남
3. 짧은 질문: 공백을 빼고 10자 이하
- 건너뛴 질문은 원래 질문으로 검색하고, 추가 시간은 0초로 센다.

- 바꾸기 정확도(사람 판정 `human_rewrite_ok`): 기준과 같은 문장은 판정을 이어받고, 다른 문장만 새로 판정
- 비용(토큰 × 공식 가격)
- D: 건너뛴 턴 수와 그중 **"바꿔야 하는데 건너뛴 수"**(사람 판정)

**채택 규칙**
1. 정확도가 기준보다 나빠지지 않은 설정만 후보
2. 후보 중 이어지는 질문의 평균 추가 시간이 가장 짧은 것
3. 단독으로 좋은(후보이면서 기준보다 빠른) 설정끼리 조합 하나를 마지막에 한 번 더 잰다(같은 18턴 × 2회)
