- 쪽 표시와 쪽 값이 함께 있을 때 AI가 쪽 번호를 `chunk_id`에 넣는 이유(2단계는 둘 중 하나를 없애면 이번 입력에서 일어나지 않았다는 것까지만 보였다)
- 2단계 결과가 5C 입력 밖에서도 같은지(3단계에서는 검색 안 된 chunk_id가 0건이라 ②를 판단할 수 없었음)
- 사용자 테스트의 C "어디가 문제?" 찾지 못함이 어느 검사에서 났는지(로컬 3회는 모두 찾음, 운영 기록 없음)
- 실제 비용(OpenAI 사용량 화면과 대조하지 않음)
- 같은 입력을 여러 번 돌렸을 때의 변동(3단계는 각 1회)
