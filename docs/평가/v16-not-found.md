### 1. 답변 AI에 가는 입력과 출력 형식

- **조각 태그:** `app/answer/prompting.py:16-17`. 속성 순서는 `chunk_id` → `doc_type` → `title` → `page`, 그 뒤 줄에 조각 본문

  ```python
  f'<chunk chunk_id="{c.id}" doc_type="{c.doc_type}" title="{_data(c.title)}" page="{c.page if c.page is not None else ""}">\n'
  f"{_data(c.content)}\n</chunk>"
  ```

  - 속성 값은 모두 따옴표 안의 글자다(`chunk_id="83"`, `page="55"`)
  - 사용자 메시지 모양: `<chunks>` 안에 조각들, 그 뒤 `<question>`(`prompting.py:20`). 시스템 메시지는 `app/answer/prompts/answer_v{버전}.txt`(`prompting.py:14`), 기본 `v1`(`app/core/config.py:20`)
