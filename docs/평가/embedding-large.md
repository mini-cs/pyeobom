**0단계: 준비**

**B-1 (1단계, 검색만, 한 실행 안에서 운영·후보)**: 개발용 P 5위 안이 운영보다 3문장 이상 많음(20문장 중) **그리고** 30문항 5위 안이 운영보다 1문항 넘게 떨어지지 않음. 기록용: 순위 구간(1~5/6~10/11~20/21~50/51~100/100위 밖)과 문장별 순위 변화. 통과하지 못하면 미채택, 확인용 세트 봉인 유지

**B-2 (3단계, 답변까지, 개발용 21문장, 운영과 후보 각 2회, 한 실행 안, 사용자가 전부 가린 판정지로 판정, ⑰)**
- 사람 판정 정답이 운영보다 3문장 이상 많음(21문장 중), 환각 0
- 질문당 비용이 운영의 1.5배 이하
- 같은 실행 안 응답 시간 증가가 0.5초 이하
- 5C 확인 3회 모두 찾음(Fable 설계 6절과 같은 정의)
- 함께 보기(채택 판정과 별개): 두 벌 모두에서 "설명서에 없는 코드에 다른 코드의 해결 절차를 붙이는" 환각이 나오면 따로 기록하고 사용자에게 알린다(결정기록 032 다시 볼 조건)
- 통과하지 못하면 미채택, 확인용 세트 봉인 유지

**B-3 (4단계, 확인용 세트, 3단계를 통과했을 때만 연다)**
- 확인용 세트: 결정기록 031 구성 그대로(봉인된 지난 확인용 20문장 + 새 응답자 3명의 확인용 10카드 문장, 2026-11-13까지), 최대 50문장. 그 뒤 응답은 넣지 않고 수만 기록
- 대상: 확인용 + 1차 30문항 + 이어지는 질문 31턴, 운영과 후보를 한 실행 안에서 각 2회
- 확인용 5위 안이 운영보다 10%p 이상 오르고(실제 검색 분모로 문장 수로 바꿔 올림, 분모 50이면 5문장), 사람 판정 정답이 운영보다 많음, 환각 0
- 30문항 사람 판정이 운영보다 2문항 넘게 떨어지지 않음, 환각 0
- 이어지는 질문 정답이 운영보다 1턴 넘게 떨어지지 않음, 환각 0
- 질문당 비용·응답 시간은 B-2와 같음
- 판정: 확인용 답은 사용자가 전부(가린 판정지), 회귀(30문항·이어지는 질문)는 ⑳(규칙·AI·사람 섞기, 명시적 예외)

**결론**: B-1·B-2·B-3을 모두 통과하면 채택 → 운영 반영(설계 8절, 합격선 운영 30문항 2회 24/30 이상·환각 0). 하나라도 통과하지 못하면 미채택

**일정과 멈춤 규칙** (설계 7절)
1. 1단계를 11/22 밤까지 끝내지 못하면 미완료로 기록한다(통과 못 하면 그 자리에서 미채택)
