- **자동 결과가 v1과 달라진 문항:**
  - q24(CH10): 오답 → 정답. 진단 쪽(34·49쪽)이 덧붙어 "없다"고 밝힌 뒤 스마트 진단을 안내했고, 34쪽을 인용했다.
  - q07(tE): 정답 → 오답. "tE"가 LG 가이드에 있어 진단 조각은 덧붙지 않았다(검색 결과도 v1과 같다). 답이 "물이 식은 뒤"라고 써서 핵심 단어 "뜨거운 물"이 빠졌다. **v2a 변경과 관계없는 답변 표현 차이**로 보인다.
- **응답 시간 차이(평균 5.5 → 4.7초)는 v2a 효과가 아니라 측정 변동이다.** v2a는 코드가 근거에 없는 질문에만 조각을 덧붙여 입력을 오히려 늘린다. 같은 v2a를 다시 돌린 2차는 평균 5.1초였다. 모두 로컬 실행 기준이다.

## 사람 판정 방식
- **사람이 다시 판정한 문항:** v1과 자동 결과가 달라진 문항(q07·q24)과, v1에서 사람 판정이 자동과 달랐던 문항(q05·q06·q08·q25)
- **나머지 24문항:** v1 사람 판정을 그대로 쓴다. 자동 결과가 같고 v1에서 자동과 사람 판정이 일치한 문항이기 때문이다.
- 판정은 `evaluation/results/v2a-2026-11-01.csv`의 `human_verdict` 열에 적는다.

- **자동 정답 판정이 다른 문항은 30개 중 2개다.**
  - q03: 1차 정답 → 2차 찾지 못함(근거 쪽은 검색됨, 답변 실패)
