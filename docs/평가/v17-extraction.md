## 판단 기준 (설계 7절 그대로, 측정 전 확정, 결과를 본 뒤 바꾸지 않음)

- "N문장 넘게 떨어지지 않음"은 같은 실행 안의 비교 대상과 견준다.
- 검색 적중은 함정을 빼고, 사람 판정 정답은 함정을 포함한 전체로 센다(결정기록 029와 같음).
- %p는 분모에 맞춰 문장 수로 바꾸고 올림한다.

### A. 쪽 표시 지우기: 나빠지지 않으면 채택 (비교 대상: 운영 그대로)

- A-1 (1단계, 사용자 결정)
  - 30문항 5위 안이 운영보다 1문항 넘게 떨어지지 않음
  - 개발용 P 세트 5위 안이 운영보다 1문장 넘게 떨어지지 않음
- A-2 (3단계, 사용자 결정): 5C 확인 3회 모두 찾음
- A-3 (회귀, 사용자 결정 2026-11-16)
  - 3단계 개발용 사람 판정 정답이 운영보다 1문장 넘게 떨어지지 않음, 환각 0
  - 1차 30문항 사람 판정이 운영보다 2문항 넘게 떨어지지 않음, 환각 0
  - 이어지는 질문 정답이 운영보다 1턴 넘게 떨어지지 않음, 환각 0
  - 4단계를 여는 경우에만: 확인용 5위 안과 사람 판정 정답이 각각 운영보다 1문장 넘게 떨어지지 않음, 환각 0
  - 4단계를 열지 않는 경우: 30문항과 이어지는 질문은 6절 4단계의 "여는 조건"에 적은 실행으로 잰다.

### B. 도구·자르기: 올라야 채택 (비교 대상: 쪽 표시만 지운 것, 계획 1-4의 숫자)

- B-1 (1·2단계, 검색만)
  - 개발용 P 세트 5위 안이 15%p 이상 오름(20문장 중 3문장 이상)
  - 30문항 5위 안이 1문항 넘게 떨어지지 않음
- B-2 (3단계)
  - 개발용 사람 판정 정답이 10%p 이상 오름(21문장 중 3문장 이상), 환각 0
  - 질문당 비용이 1.5배 이하
  - 같은 실행 안 응답 시간 증가가 0.5초 이하
- B-3 (4단계)
  - 확인용 5위 안이 10%p 이상 오르고, 사람 판정 정답이 더 많음, 환각 0
  - 30문항 사람 판정이 2문항 넘게 떨어지지 않음, 환각 0
  - 이어지는 질문 정답이 1턴 넘게 떨어지지 않음, 환각 0
  - 비용·시간은 B-2와 같음
- 계획 1-4는 30문항(27/30)과 이어지는 질문(17/18)을 고정 숫자로 견줬다. 이번에는 같은 실행 안의 비교 대상과 견준다. 허용 폭(2문항, 1턴)은 같다(채팅 Claude 해석, 결정기록 028의 "같은 실행 안 비교").

### 둘을 합쳐 정하는 법 (채팅 Claude 기본값)

- **B를 반영하려면 최종 후보도 A 기준을 운영 그대로와 견줘 모두 통과해야 한다**(A-1·A-2·A-3, 검토 반영). 그래서 최종 후보도 5C 3회를 모두 찾아야 한다. 허용 폭이 겹쳐서(A에서 1, B에서 1) 운영보다 더 많이 떨어지는 일도 막는다.
- A·B 모두 통과: B를 반영한다(B에는 쪽 표시 지우기가 들어 있다).
- A만 통과: 쪽 표시 지우기만 반영한다.
- 둘 다 통과하지 못함: 운영을 그대로 두고 미채택 결정기록을 남긴다.
