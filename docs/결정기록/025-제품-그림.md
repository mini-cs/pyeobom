# 025. 제품 그림은 세 모델 모두 같은 스타일의 AI 일러스트

- 날짜: 2026-11-08(설계 4절) ~ 2026-11-10(사용자 결정 덧붙임)
- 상태: 확정
- 관련: 설계 `docs/superpowers/specs/2026-11-08-chat-redesign-design.md` 4절, 계획 3 Task 4, 그림 `public/images/models/`, 결정기록 009(저작권)·021

## 배경

- v1.5 모델 선택 화면은 카드마다 제품 그림을 둔다. 실제 제품 사진을 쓸 수 있는지 조사했다(설계 4절, 2026-11-08).
  - 삼성 뉴스룸: 직접 제작 이미지는 자유 이용, 워터마크 이미지는 제한, 변형 금지. 2026년형 비스포크 AI 콤보 출시 기사 사진이 있지만 터치형·다이얼형 두 종류 중 하나뿐이다.
  - LG 뉴스룸: CCL 2.0, 비영리·개인 목적만. FX24GNG는 이전 세대 사진만 있고, SQ06FA1WDS는 사진이 없다.
  - 판매 페이지 사진: 쓸 근거가 없다.

## 결정

1. **세 모델 모두 같은 스타일의 일러스트로 통일한다.** 로고 없이 생김새만 그리고, 같은 선 굵기·크기·흑백 스타일이다.
   - 이유: 세 모델에 쓸 수 있는 사진이 고르게 없고(위 조사), 사진마다 이용 조건이 다르다. 앞으로 모델을 더해도 같은 방식으로 맞출 수 있다.
   - 그림 3장(SVG)은 11/8 설계 대화에서 채팅 Claude가 만들었고, 11/10 저장소에 넣었다.
2. **SVG의 C2PA 출처 정보는 지우지 않는다**(2026-11-10 사용자 결정). AI로 만든 그림이라는 기록이다. 파일 크기는 장당 약 8.5KB이고, 미리보기 측정에서 모델 화면 성능 0.99였다(`docs/평가/v15-ui.md`).
3. **AI 그림 안내 한 줄을 모델 선택 화면의 카드 아래에만 둔다**(2026-11-10 사용자 결정): "제품 그림은 AI로 그린 일러스트예요. 실제 제품과 다를 수 있어요."(12px, 보조 회색). 그림은 모델 선택 화면에만 나온다.
4. **카드에 공식 제품 링크를 넣지 않는다**(2026-11-10 사용자 결정, 설계 4절의 "카드에 공식 사이트 링크"와 다른 점). 이유는 결정기록 021 결정 4(단종·주소 변경 관리, 판매 페이지라 비영리 안내와 어긋남).
5. 그림은 꾸밈으로 보고 `alt=""`로 둔다. 바로 옆에 모델 이름이 있다.

## 맞바꾼 것

- 실제 제품과 생김새가 다를 수 있다(안내 문구로 알림).
- 사용자가 자기 제품과 그림을 대조해 모델을 고르기는 어렵다. 모델 고르기는 "모델명 찾는 법" 안내가 맡는다.

## 다시 볼 조건

- 제조사에서 이용 조건이 분명한 공식 제품 사진을 세 모델 모두 받을 수 있게 되면 다시 본다.
- 모델을 더할 때 같은 스타일로 그림을 만들고 C2PA 정보와 안내 문구를 같은 방식으로 둔다.
