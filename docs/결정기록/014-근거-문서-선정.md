## 적용 범위가 달라 뺀 것

- **페이지 단위:**
  - 삼성전자서비스 solution/40132: 플렉스워시 제품 한정
  - LG 통돌이 세탁기 에러코드 페이지: 통돌이용
  - 공식 자료라도 적용 범위가 다르면 근거로 쓰지 않는다. 펴봄이 막으려는 "다른 모델 정보 섞임"을 데이터 단계에서 막은 사례다.
- **문단 단위 (결정 A, 2026-10-28):** 삼성 oC·LC 페이지의 플렉스워시 전용 문단은 전처리에서 뺀다. `documents.json`의 두 문서에 `"exclude_keywords": ["플렉스워시"]`를 넣는다. 페이지 단위 원칙을 문단 단위까지 적용한 것이다.
  - oC: "플렉스워시 제품은 상부 전자동 이상일 경우…"로 시작하는 1문장
  - LC: `[플렉스워시 제품, 누수 점검 확인 안내]` 소제목으로 시작하는 단락 전체
- **LC 페이지의 "LC1 에러" 블록도 소제목째 뺀다.** 일반 드럼에도 해당해 보이지만, 제조사가 플렉스워시 소제목 아래에 두었으므로 우리 모델에 맞는지 확인할 수 없다. 정확성을 우선해서, 확인되지 않은 근거는 쓰지 않는다.
- **LC 마지막 일반 안내 줄도 함께 빠지는 것을 감수한다 (2026-10-29).** 플렉스워시 소제목 뒤에 다른 소제목이 없다. 그래서 페이지 끝의 "※ 증상이 동일하게 나타난다면 엔지니어 점검을 받아보시기 바랍니다."도 같이 빠진다. 같은 안내가 삼성 oC·FC 가이드에도 있어 정보 손실이 작다.
