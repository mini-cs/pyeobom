# 009. 저작권 정책: 원본·조각 비공개, 짧은 인용, 고지, 허락 문의

- 날짜: 2026-10-27
- 상태: 확정
- 배경: 삼성전자서비스 약관 제20조와 LG전자 약관 제8조는 사이트 정보를 사전 승낙 없이 영리 목적으로 이용하거나 제3자에게 이용하게 하는 것을 금지하는 취지다. 비영리 포트폴리오라도 배포된 서비스가 다른 사람에게 설명서 내용을 보여 주는 것은 걸릴 여지가 있고, 저작권법상 비영리가 자동으로 허용되지는 않는다(제35조의5 공정이용 판단 요소).
- 선택지:
  - A. 원본과 조각을 저장소에 두고 자유롭게 보여 줌: 재현은 쉽지만 위험이 큼
  - B. 원본·조각 비공개 + 화면에는 짧은 인용과 출처 + 고지 + 허락 문의
  - C. 가상 설명서만 사용: 위험은 없지만 "공식 설명서 근거"라는 차별점이 사라짐
- 결정: B. 원본 PDF·저장한 가이드 HTML은 GitHub에 올리지 않고(README에는 공식 링크와 받는 방법만), 조각 텍스트는 Neon에만 둔다. 화면에는 1~2문장 인용 + 쪽(또는 가이드 제목) + 공식 링크만 보여 준다. 비영리·출처 고지를 넣고 제조사에 사용 허락을 문의한다. 해결 가이드는 필요한 페이지만 직접 저장한다(자동 수집 없음). C는 허락이 불확실할 때의 Plan B로 둔다.
- 맞바꾼 것: 다른 사람이 저장소만으로 똑같이 재현할 수 없다. 원본을 각자 공식 사이트에서 받아야 한다.
- 다시 볼 조건: 제조사가 거절하거나 삭제를 요청하면 해당 브랜드를 빼거나 가상 설명서로 바꾼다.
- 관련: 기획서 8장
