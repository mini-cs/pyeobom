## 한계

- **결론이 판정 기준 하나에 걸려 있다.** 최종 판정 기준으로 A-3 통과다. 다만 '설명서에 없는 안전 조치·문의 안내 덧붙임'을 환각으로 보느냐에 결론이 걸려 있다.
  - 1차 사람 판정이었다면 실패했다: 쪽 표시 쪽 30문항에 환각(192·461).
  - 사용자가 정답으로 유지한 330(쪽 표시, d09-1)이나 267(쪽 표시, q24) 하나만 환각으로 봐도 쪽 표시 쪽 환각 1로 A-3에 실패한다. 315(운영 q14)·354(운영 d04-2)는 운영 쪽이다. 넷을 모두 환각으로 보면 두 벌 모두 환각 2개씩이다.
  - 판정 변경은 모두 대응표 공개 전이었고, 판정은 사용자가 했다.
- **회귀 판정은 사람이 전부 하지 않았다(⑳, 설계 7절 A-3·2절의 명시적 예외).** "찾지 못함" 26개는 규칙으로, 세 AI가 일치한 118개는 AI 판정으로, 나머지 75개(갈림 28, 경계 17, 표본 30)는 사람이 판정했다. 표본 30개에서 사람과 세 AI가 다른 것은 0개였다.
  - 판정 AI 조건(자기 보고): Claude는 메모리가 켜져 있었고 이 프로젝트 안에서 열었는지 확인하지 못했다. ChatGPT(화면 표시 "GPT-6", 무료)는 답을 만든 모델과 같을 가능성이 있다(공식 확인 못 함). Gemini는 자동 모드라 실제 모델을 확인하지 못했다.
  - AI 판정 자료의 원문은 기대 근거 쪽뿐이었다.
- **회귀는 "같은 실행 안"이 아니었다.** 설계·계획은 같은 실행 안 비교인데, 회귀는 운영 → 쪽 표시 → 쪽 표시 → 운영 순서(사용자 지시)로 따로 돈 4차례를 견줬다. 3단계는 한 실행 안에서 두 벌을 함께 돌렸다.
- **사람이 다시 볼 때 채팅 Claude가 원문 검색 결과를 보여 줬다.** 판정은 사용자가 했다.
