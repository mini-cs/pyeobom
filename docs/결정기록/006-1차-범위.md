# 006. 1차 범위: 핵심 흐름 우선, 추가 기능은 여유 시

- 날짜: 2026-10-27
- 상태: 확정
- 배경: 1차는 사실상 5일이고(이후 마감이 11/3 오전으로 당겨짐), 평가는 "핵심 흐름이 정확하고 안정적인가"를 본다.
- 선택지:
  - A. 기능을 넓게(로그인, 기록 저장, 대화 이어 가기, 사진 인식 등)
  - B. 핵심 흐름(모델 선택 → 질문 → 근거 답변 또는 찾지 못함)만 완성하고, 추가 기능은 v2 측정 뒤 여유가 있을 때 우선순위대로
- 결정: B. 로그인·기록 저장(2차), 어르신·상담원 화면(3·4차), 사진·음성 입력, 대화 이어 가기, 사용자 설명서 업로드, 해결 가이드 자동 수집은 1차에서 하지 않는다. 여유 기능은 캐싱 → 질문당 비용 측정 → 👍/👎 저장 → 스트리밍 순서로만 추가한다.
- 맞바꾼 것: 데모가 화려하지 않다. 대화를 기억하지 않아 같은 맥락을 다시 입력해야 한다.
- 다시 볼 조건: 핵심 흐름과 v1 → v2 비교가 끝나고 시간이 남을 때만 위 순서대로 연다.
- 관련: 기획서 3.3, 3.5, 12장 "시간이 부족할 때 줄이는 순서"
