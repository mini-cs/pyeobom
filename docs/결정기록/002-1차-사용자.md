# 002. 1차 사용자: 자취생 중심, 어르신·상담원은 2~4차

- 날짜: 2026-10-27
- 상태: 확정
- 배경: 자취생, 어르신, 고객센터 상담원 모두 가전 설명서 문제를 겪지만, 사용자마다 "좋은 답"의 형식과 평가 지표가 다르다(어르신은 쉬운 말·큰 글씨, 상담원은 빠른 검색·여러 모델).
- 선택지:
  - A. 세 사용자 모두 1차에 포함: 시장이 넓어 보이지만 5일 안에 평가 기준이 흩어짐
  - B. 자취생만 1차 주인공: 원룸 옵션 가전처럼 설명서가 없는 상황이 뚜렷하고, 캠프 동기로 설문·사용자 테스트가 가능
- 결정: B. 1차는 원룸·오피스텔 옵션 가전을 쓰는 자취생·세입자만 주인공으로 두고, 어르신 모드는 3차, 상담원 화면은 4차로 넘긴다.
- 맞바꾼 것: 어르신처럼 필요가 더 클 수 있는 사용자를 1차에서 다루지 않는다.
- 다시 볼 조건: 설문(최종 21명)에서 핵심 사용자(옵션 가전 원룸)는 6명이었다. 2차 기획 때 자취생 수요가 약하다고 판단되면 우선순위를 다시 본다.
- 관련: 기획서 1장 6번, 2.1, 10장
