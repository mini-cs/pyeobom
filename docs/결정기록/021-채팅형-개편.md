# 021. v1.5 채팅형 화면 개편 (검색형 → 랜딩·카테고리·모델·채팅)

- 날짜: 2026-11-08(설계) ~ 2026-11-11(PR #54 병합, 운영 반영)
- 상태: 확정 (계획 3 채택 조건 1~4 통과)
- 관련: 설계 `docs/superpowers/specs/2026-11-08-chat-redesign-design.md`, 계획 `docs/superpowers/plans/2026-11-10-chat-redesign-plan.md`, 측정 `docs/평가/v15-ui.md`, 결정기록 007·012(이어받아 바꿈)·022·023·024·025·027

## 배경

- 1차 화면은 **결정기록 007 C안 검색형**이었다. 질문 1개에 답 1개이고, 대화를 기억하지 않아 채팅형(A안)은 "앞 대화를 기억한다"는 잘못된 기대를 준다는 이유였다. 007의 다시 볼 조건은 "대화 이어 가기를 넣는다면 채팅형을 다시 검토한다"였다.
- 계획 2에서 서버가 이어지는 질문을 지원하게 됐다(앞 대화로 질문을 바꾼 뒤 검색, 결정기록 023). 007의 다시 볼 조건이 채워졌다.
- **결정기록 012**는 검색창 위 소개 영역(랜딩 A안)이었고, 질문하면 소개 영역이 접혔다. 접힘을 알아채는지는 사용자 테스트를 하지 못해 보류돼 있었다.

## 결정

1. **화면 흐름:** 랜딩(처음 열면 주소와 상관없이 항상) → 카테고리 → 모델 선택 → 채팅, ☰로 여는 지난 대화 서랍. `#` 주소로 이동해 브라우저 뒤로 가기를 지원한다.
   - 007 검색형 → 채팅형. 이어지는 질문이 실제로 동작하므로 007의 A안 반대 이유(잘못된 기대)가 없어졌다.
   - 012 소개 영역 → 별도 랜딩 화면. 소개를 접는 움직임은 없앴다. 이름 "펴봄"과 웹 제목, 신뢰 포인트 3개는 그대로 이어받는다.
2. **화면 개편은 PR 하나(PR #54)로 묶었다**(계획 3 사용자 결정 10). CLAUDE.md "기능 하나 = 브랜치 하나 = PR 하나"의 명시적 예외다.
   - 이유: `main` 병합이 곧 운영 배포라, Task마다 나눠 병합하면 반쯤 만든 화면(채팅이 없는 랜딩 등)이 운영에 나간다.
   - 작업 단위 검토는 Task마다 테스트 → 구현 커밋과 작업별 검토로 했다.
3. **바꾼 질문 표시 문구는 "'○○'로 찾았어요"**(계획 3 사용자 결정 9). 설계 1절·11절의 "이렇게 이해했어요"는 같은 줄의 옛 이름이다. 바꾼 질문이 가린 질문과 같으면 숨긴다.
4. **모델 카드에 공식 제품 링크를 넣지 않는다**(2026-11-10 사용자 결정, 설계 1·2·4절과 다른 점).
   - 이유: 모델 고르기는 "모델명 찾는 법"이 맡는다. 제품 페이지는 단종·주소 변경을 관리해야 한다(FX24GNG 단종 표시). 가격·구매 버튼이 있는 판매 페이지라 비영리 안내와 어긋난다.
   - 서비스센터 연결은 "찾지 못함" 상태의 고객센터 링크로 1차 그대로 둔다.
5. **AI 그림 안내는 모델 선택 화면의 카드 아래에만 한 줄** "제품 그림은 AI로 그린 일러스트예요. 실제 제품과 다를 수 있어요."(2026-11-10 사용자 결정, 그림 정책은 결정기록 025)
6. **채팅 화면 세부(2026-11-10 사용자 결정, Task 5 확인)**
   - 설명서 링크 옆 검색어(모델 코드)는 "코드는 모델 선택 화면에서만" 규칙의 유일한 예외(내려받기 페이지가 모델 코드로 찾음)
   - 채팅 화면에는 하단 고지를 두지 않는다(랜딩·서랍에 있음)
   - 다른 브랜드 안내는 링크 대신 앱 안 버튼 "모델 다시 고르기"(카테고리로). 서버가 `reason: "other_brand"`로 구분해 준다(결정기록 027)
   - 모델 카드는 항상 새 대화로 시작한다. 이어 하기는 최근 대화 카드와 서랍에서만
7. **삼성 두 번째 추천 카드 교체(2026-11-11 사용자 결정):** "물이 안 빠지고 5C가 떠요" → "물이 안 빠지고 탈수가 안 돼요"
   - 이유: 바꾸기 전 문장이 로컬 3회 모두 "찾지 못함"이었다. 답변 AI가 인용의 조각 번호 자리에 쪽 번호를 적어 검증에서 떨어졌다(인용 번호 버그, 다음 계획에서 다룸).
   - 바꾼 문장은 측정 전에 정한 기준(3회 모두 찾음, 답이 있는 쪽 인용)을 통과했다(3회 모두 72쪽). 사람 판정도 3회 모두 정답. 연 평가 질문과 겹치지 않는다
8. **근거 접기(2026-11-11 사용자 결정):** 근거는 쪽 번호가 보이는 접힌 한 줄이다. 펼치면 출처별 한 상자(링크 없음)가 나오고, 아래 "공식 설명서를 드릴까요?" 버튼 하나를 누르면 링크가 나온다. 공용 가이드 경고는 접지 않는다.
   - 이유: 근거 상자마다 "공식 설명서 받기"가 붙고 같은 쪽 상자가 여러 개라 답과 근거가 겹쳐 보였다(사용자 PC 확인).
   - 모양은 디자인 가이드 6절 7·8, 인용은 원문 그대로 `blockquote`(원문 "•"와 목록 기호가 겹치지 않게).
9. 화면 확인에서 함께 고친 크기·포커스 링·세 번째 타일 등 디자인 체계 결정은 결정기록 024 결정 8~11에 있다.
