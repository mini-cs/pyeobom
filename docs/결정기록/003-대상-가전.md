# 003. 대상 가전: 세탁기 + 에어컨

- 날짜: 2026-10-27 (설명서 수는 2026-10-28 결정기록 014에서 확정)
- 상태: 확정
- 배경: 원룸 옵션 가전 중 사용법·에러 질문이 자주 생기는 가전을 골라야 했다. 테스트 30개를 너무 많은 가전에 나누면 가전당 질문 수가 적어 지표를 믿기 어렵다.
- 선택지:
  - A. 세탁기만: 깊게 볼 수 있지만 "여러 가전을 한 곳에서"라는 차별점이 약함
  - B. 세탁기 + 에어컨: 원룸 기본 옵션 두 가지, 질문 유형(에러 코드·청소·예약)이 겹쳐 비교하기 좋음
  - C. 세탁기 + 에어컨 + 컴퓨터(노트북): 범위가 넓어 분야당 질문이 약 10개로 줄어듦(결정기록 008)
- 결정: B. 세탁기와 에어컨, 설명서 3~4개로 시작한다. 이후 1일차에 설명서 3개(삼성 세탁건조기, LG 드럼, LG 벽걸이 에어컨) + 공식 해결 가이드 8개로 확정했다(결정기록 014).
- 맞바꾼 것: 냉장고·전자레인지 등 다른 옵션 가전은 다루지 않는다. 세탁기는 드럼 계열만 다루고 통돌이(설문 7명)는 빠진다.
- 다시 볼 조건: 2차에서 새 카테고리 추가에 걸리는 시간을 확장성 지표로 재면서, 설문 요청이 있었던 건조기·통돌이를 우선 검토한다.
- 관련: 기획서 1장 7번, 3.2, 결정기록 014
