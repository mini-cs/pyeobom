# 026. 1차 기준값 측정 도구와 방법

- 날짜: 2026-11-09
- 상태: 확정 (측정 완료, 결과는 `docs/평가/baseline-v1.md`)
- 배경: v1.5 채팅형 개편(설계 `docs/superpowers/specs/2026-11-08-chat-redesign-design.md`) 전에 1차(태그 `v1.0`)를 재서, 개편 후 같은 방법으로 다시 재고 비교한다(설계 8절, 계획 `docs/superpowers/plans/2026-11-08-baseline-v1-measurement.md`).

## 결정

- **도구 6개로 잰다:** Lighthouse(화면 속도), axe-core + Playwright(접근성), Langfuse(단계별 시간·토큰·비용), DeepEval(AI 채점), Locust(동시 요청 응답 시간), Promptfoo(방어 시험).
  - 고른 이유(설계 8절): 개편이 바꾸는 것(화면, 질문 흐름, AI 호출 수)을 각각 하나씩 재는 도구이고, 모두 무료(오픈소스·무료 플랜)라 비용은 OpenAI API 사용량뿐이다.
  - 비용은 합계 상한 2달러로 두고, 실행마다 장부에 예상 비용을 먼저 적고 `check_budget`을 통과한 뒤 실행했다. 실제 합계는 약 0.52달러.
- **운영에는 추적(Langfuse)을 켜지 않는다.**
  - 추적 코드는 키가 없으면 아무것도 하지 않고, Vercel 환경 변수에는 Langfuse 키를 넣지 않았다. 측정은 로컬 평가 30문항으로만 했다.
  - 이유: 운영 동작을 바꾸지 않는 것이 이번 계획의 조건이다. 운영 사용자의 질문을 외부 서비스로 보내지 않는다.
  - 보내는 것도 단계별 시간(embed, db_connect, search, llm), 토큰 수, 가린 질문뿐이다. 프롬프트·설명서 조각·답 본문은 보내지 않고, OpenAI 자동 기록(래퍼·자동 계측)은 쓰지 않는다(`tests/core/test_observability.py`로 고정).
- **AI 채점(DeepEval·Promptfoo)은 보조 지표다. 정답률의 최종 기준은 1차 사람 판정이다.**
  - DeepEval은 1차 규칙(설명서에 없는 코드는 "없다"고 밝힘)을 모르고 곁들인 안내를 감점했다(q24, q02·q04·q10). 사람 기준 오답 3문항은 "찾지 못함"이라 채점 대상에서 빠져 오답 탐지 능력도 확인하지 못했다.
  - 채점 설정이 결과를 바꾼다: 추론 강도 `minimal`에서 q01 Faithfulness가 1.00 → 0.00으로 뒤집혔다. 그래서 채점 모델·추론 강도·도구 버전을 고정하고 v1.5에도 같은 설정을 쓴다.
- **부하(Locust)·공격(Promptfoo)은 미리보기에만 보낸다.**
  - 이유: 운영과 같은 OpenAI 선불 잔액·DB를 쓰므로 운영 사용자에게 영향을 주지 않게 한다. 운영 주소는 코드에서 거부한다(`assert_not_production`).
  - 미리보기는 배포 보호를 유지한 채, 측정 전용 자동화 우회 값을 헤더(`x-vercel-protection-bypass`)로만 보냈다. 측정이 끝난 뒤 사용자가 그 값을 Vercel과 `.env`에서 삭제했다.
  - Promptfoo 레드팀은 `--remote` 없이 우리 OpenAI 키로 로컬 생성만 썼다. 원격 추론 플러그인·전략(hijacking, indirect-prompt-injection, jailbreak:meta, jailbreak:composite)은 뺐다.

## 측정 절차에서 정한 것

- Locust는 측정 전 질문 2개로 서버를 깨우고(결과 제외), 리다이렉트를 따라가지 않으며 답 JSON이 아닌 응답은 실패로 센다. 응답 검사가 없던 측정 1회는 답이 아닌 페이지를 성공으로 세어 버렸다.
- Lighthouse는 모바일 3회 중앙값, axe는 화면 4상태(빈 화면, 답, 찾지 못함, 오류)를 고정 응답으로 띄워 잰다.

## 하지 않은 것

- 측정에서 찾은 문제는 고치지 않았다(이번 계획은 측정만). 접근성 2건·CLS는 계획 3, 근거 관련성·다른 브랜드 코드 응답 정책·응답 시간은 계획 2·2차 후보로 넘겼다.
- 스킬은 `promptfoo-evals`만 설치했다. 나머지 공식 후보 3개는 확인 없는 외부 명령 허용, 앱 코드 자동 수정, 외부 서버 전송 때문에 보류했다(`baseline-v1.md` "스킬 검토 결과").
