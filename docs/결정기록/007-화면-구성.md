# 007. 화면 구성: C안 검색형

- 날짜: 2026-10-27
- 상태: 확정
- 배경: 1차는 질문 1개에 답변 1개이고 대화를 기억하지 않는다. "공식 설명서 근거"라는 차별점이 화면에서 드러나야 한다.
- 선택지:
  - A. 채팅형: 익숙하지만 "앞 대화를 기억한다"는 기대를 줘서 실제 동작과 어긋남
  - B. 단계형(가전 → 브랜드 → 모델 → 질문): 모델명 찾기 안내가 쉽지만 질문까지 클릭 3번, 두 번째 질문부터 번거로움
  - C. 검색형: 검색창 하나와 답변 카드, 근거 카드가 눈에 띔
- 결정: C. B의 장점(모델명 찾는 법 안내)은 C의 "모델 변경" 화면에 넣는다.
- 맞바꾼 것: 이어서 묻는 대화형 경험을 주지 않는다.
- 다시 볼 조건: 2차 이후 대화 이어 가기를 넣는다면 채팅형을 다시 검토한다.
- 관련: 기획서 4.1
- 덧붙임 (2026-11-11): 다시 볼 조건(대화 이어 가기)이 채워져 v1.5에서 채팅형(랜딩 → 카테고리 → 모델 → 채팅)으로 바꿨다. 결정기록 021
