# 008. 컴퓨터(노트북) 카테고리: 2차 이후

- 날짜: 2026-10-27
- 상태: 확정
- 배경: 컴퓨터 고장 질문도 수요가 있지만, 1차 범위에 넣을지 정해야 했다.
- 선택지:
  - A. 1차에 포함: 수요가 넓지만 원인이 OS·프로그램·부품에 걸쳐 "그 모델의 설명서 한 권"으로 답하기 어려움, 테스트 30개가 세 분야로 나뉘어 분야당 약 10개
  - B. 2차 이후 카테고리 확장으로 미룸
- 결정: B. 2차에 엔진은 그대로 두고 설명서만 추가해 "새 카테고리 추가에 걸린 시간"을 확장성 지표로 보여 준다. 범위는 "노트북 제조사 설명서 기반 고장 해결 안내"로 한정하고 분해 수리는 제외한다.
- 맞바꾼 것: 1차 사용 범위가 가전 두 종류로 좁다.
- 다시 볼 조건: 2차 기획 때 설문·사용자 요청을 보고 노트북과 건조기·통돌이 중 무엇을 먼저 넣을지 정한다.
- 관련: 기획서 3.4
