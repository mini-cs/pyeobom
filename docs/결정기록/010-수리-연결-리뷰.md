# 010. 수리 연결·리뷰 로드맵

- 날짜: 2026-10-27
- 상태: 확정
- 배경: 설명서로 해결되지 않는 문제(찾지 못함, "서비스센터 문의" 안내)에서 사용자를 그냥 두면 문제 해결이 끝나지 않는다. 동시에 1차에서 다룰 범위는 아니다.
- 선택지(리뷰 자격 확인):
  - A. 연결 기록 기준: 구현이 단순하고 개인정보 부담이 없지만 실제 방문은 보장 못 함
  - B. 영수증 사진 인증: 신뢰도는 높지만 영수증 속 개인정보 처리와 운영 부담
  - C. 작성 기간 제한(예: 연결 후 30일): 단독으로는 약함
- 결정: 2차 공식 서비스센터 연결 + 리뷰(연결 기록 기준 + 기간 제한 보조), 3차 주변 사설 수리점(카카오맵 로컬 API 1순위 후보), 4차 수수료 시나리오·리뷰 관리. 수수료를 받더라도 광고 노출과 리뷰 순위를 분리하고 광고임을 표시한다. 정확한 위치는 저장하지 않는다.
- 맞바꾼 것: 1차는 "공식 고객센터에 문의해 보세요" 안내에서 멈춘다.
- 다시 볼 조건: 2차 기획 때 1차 회고를 보고 리뷰 기능을 2차와 3차 중 어디에 둘지 다시 정한다.
- 관련: 기획서 9장, 10.2
