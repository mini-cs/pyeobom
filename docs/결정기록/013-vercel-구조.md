# 013. Vercel 파이썬 배포 구조

- 날짜: 2026-10-27
- 상태: 확정 (미리보기 배포로 확인)
- 배경: 기획서 5.8에서 "Vercel 서버 함수·정적 파일 위치는 구현 단계에서 최신 문서로 확인"으로 남겨 둔 항목. 계획은 진입 파일을 `api/index.py`로 정했다.
- 확인한 문서 (2026-10-27):
  - Deploy a FastAPI app on Vercel (`/docs/frameworks/backend/fastapi`): FastAPI 인스턴스 `app`을 `app.py`·`index.py`·`server.py`·`main.py`·`wsgi.py`·`asgi.py` 또는 `src/`·`app/` 안의 같은 이름에서 찾는다. 다른 위치는 `pyproject.toml`의 `[tool.vercel] entrypoint`로 지정. `public/` 폴더 파일은 CDN에서 루트 경로로 제공하며 `app.mount()`로 붙이지 말라고 한다.
  - Using the Python Runtime (`/docs/functions/runtimes/python`): 지원 버전 3.12(기본)·3.13·3.14. 의존성은 `pyproject.toml`·`requirements.txt`·Pipfile. `/api` 폴더의 파일 기반 함수는 "기존 프로젝트" 호환 방식으로 따로 설명한다.
  - Configuring regions (`/docs/functions/configuring-functions/region`): 새 프로젝트의 함수 기본 지역은 `iad1`(워싱턴 D.C.). 대시보드 Settings → Functions 또는 `vercel.json`의 `regions`로 바꾼다. Hobby는 지역 1개.
- 선택지:
  - A. `api/index.py` 유지 + `pyproject.toml`의 `tool.vercel.entrypoint = "api.index:app"` — 계획 구조 그대로, 설정 한 줄 추가
  - B. 루트 `index.py` — 설정 없이 자동 감지, 계획의 진입 파일 위치만 달라짐
  - C. `api/` 폴더 파일 기반 함수 방식 — 기존 프로젝트용 호환 방식, 하위 경로 라우팅을 따로 맞춰야 함
- 처음 고른 것: A. **미리보기 배포에서 실패**
  - 빌드 기록: `Installing required dependencies from pyproject.toml...` — `pyproject.toml`이 있으면 `requirements.txt`를 쓰지 않아 FastAPI가 설치되지 않았다
  - 함수가 `api/index`로 만들어졌고 `/api/health`는 404 (`X-Vercel-Error: NOT_FOUND`), `/`는 `public/index.html`로 200
- 두 번째 실패: B로 옮긴 뒤에는 파이썬 빌드가 아예 돌지 않았다. 대시보드 Import 시점의 `main`에 문서만 있어 프로젝트 Framework Preset이 `Other`(정적)로 잡혔기 때문이다(`vercel project inspect`로 확인). 첫 배포에서 파이썬이 돈 것은 `api/` 폴더 호환 방식 때문이었다.
- 결정: **B + `vercel.json`의 `"framework": "fastapi"`**(문서: 이 값이 대시보드의 Framework Preset을 덮어씀, 스키마에서 `fastapi` 값 확인). 설정을 대시보드가 아니라 저장소에 둬서 다시 만들 때도 같게 한다. 진입 파일만 루트 `index.py`로 옮기고 `app/` 패키지는 그대로 둔다. `pyproject.toml`은 두지 않고 pytest 설정은 `pytest.ini`로 옮긴다. 파이썬 버전은 `.python-version` = 3.14(로컬 개발 버전과 같음, 빌드 기록 `Using Python 3.14 from .python-version`로 확인). 의존성은 `requirements.txt`(실행용)와 `requirements-dev.txt`(테스트용 pytest·httpx)로 나눠 함수 번들에 테스트 도구가 들어가지 않게 한다. 화면은 `public/`에 두고 FastAPI에 붙이지 않는다.
- 함수 지역: 기본값 `iad1`(빌드 결과 `λ ... [iad1]`). Neon DB 지역과 맞추는 일은 Task 12에서 한다.
- 맞바꾼 것: 계획의 `api/index.py` 위치를 포기했다. `pyproject.toml`을 쓰는 도구(ruff 설정 등)를 나중에 넣으려면 의존성을 그 파일로 옮겨야 한다.
- 다시 볼 조건: `pyproject.toml`이 필요해지거나, Vercel 자동 감지 위치가 바뀌면.
- 배포 확인 결과 (2026-10-27, 커밋 0327f0b 미리보기): `/api/health` → 200 `{"status":"ok"}`, `/` → `public/index.html` 200, 빌드 `λ fastapi [iad1]`, `Using Python 3.14 from .python-version`, `Installing required dependencies from requirements.txt`
- 지역 추가 (2026-10-29, 결정기록 018): `vercel.json`에 `"regions": ["sin1"]`을 넣었다. 함수 지역을 Neon(`ap-southeast-1`)과 맞추고, 설정을 저장소에 두는 이 기록의 원칙을 지역에도 적용했다.
