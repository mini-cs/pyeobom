## 막힌 것과 해결
- **MarkItDown이 PDF 쪽 경계를 잃음:** 표처럼 보이는 쪽이 하나라도 있으면 쪽들을 이어 붙인다. 그러면 `manual:<쪽>` 근거 표기를 할 수 없어서 쓰지 않기로 했다.
- **설문 반영으로 삼성 일반 드럼(`WW90T3000KW`) 추가를 시도:** 52쪽에서 글자가 1,148자만 나오는 PDF라 제외했다.
- **pdfplumber가 소수점을 지움** ("4.0 kg" → "4 0 kg", 삼성 24곳)
  - 사람이 q13 정답을 확인하다가 발견했다.
  - 사용자 컴퓨터에서 pypdfium2와 다시 비교해 확정했다(016 "수정" 절).
- **LG 에어컨은 설명서에 에러 코드표가 없음:** "모든 모델 대상" 공용 가이드를 추가했다. q23(CH05, 코드 있음)과 q24(CH10, 코드 없음 → 스마트 진단 안내)를 짝으로 만들었다.
- **Git Bash에서 `vercel curl /api/...`가 실패:** 경로가 Windows 경로로 바뀌어서였다. `MSYS_NO_PATHCONV=1`을 주고 실행해 해결했다.
- **커밋하지 않은 문서 때문에 병합 뒤 로컬 `main`으로 전환하지 못함:** 원격 `main`과 파일 내용이 같은 것을 확인한 뒤, 로컬 `main`을 원격 위치로 옮겼다.
