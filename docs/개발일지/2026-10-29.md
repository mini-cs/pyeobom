### Task 10 — `POST /api/ask` (PR #10)
- 흐름: 모델 검사 → 질문 검사 → 개인정보 가리기 → 임베딩 → 검색 → 답변 → 검증(실패 시 1회 더) → 찾지 못함
- `?debug=true`일 때만 `retrieved_refs`와 단계별 시간(`embed_ms`·`db_connect_ms`·`search_ms`·`llm_ms`)을 붙인다.
- 형식이 틀린 요청(JSON이 아님·인코딩 오류·필드 형 오류)도 400 `INVALID_REQUEST`로, 다른 오류와 같은 `{"error_code", "message"}` 형식으로 응답한다.
- 로컬 uvicorn 서버로 실제 질문을 확인했다(uvicorn 0.54.0을 `requirements-dev.txt`에 추가).

```text
POST /api/ask {"model_id": "washer-samsung-wd90h25", "question": "이불도 빨 수 있어요? 어떤 코스로 해요?"}
→ 200 found: true, 근거: 사용설명서 38쪽 "…최대 용량: 4.0 kg…"
POST /api/ask {"model_id": "aircon-lg-sq06fa1wds", "question": "이 에어컨 렌탈하면 한 달에 얼마예요?"}
→ 200 found: false, "설명서에서 찾지 못했어요. 공식 고객센터에 문의해 보세요."
```

## AI 실수
- **테스트 문자열 이스케이프 (2번):** Claude Code가 셸 heredoc으로 파일을 쓰면서 `\\n`이 실제 줄바꿈으로 들어갔다.
  - 테스트 파일: JSON이 깨져서 테스트가 검증 코드와 상관없는 이유로 실패했다.
  - 개발일지: 문장 중간에 줄바꿈이 들어갔다.
  - 둘 다 Edit 도구로 고쳤다. 이스케이프가 있는 파일은 Write·Edit 도구로 쓴다.
- **로딩 화면을 답변 화면으로 캡처:** Playwright 기다림이 너무 일찍 끝나 "답변" 캡처가 로딩 상태였다. 이미지를 열어 보고 알아챘고, 답변 카드가 나타날 때까지 기다린 뒤 다시 찍었다.
- **평균을 계산하지 않고 적음:** 지역 변경 전후 평균을 "약 2.6초"로 어림해 적었다. 다시 계산하니 2.7초였고, 고쳤다.
- **쓸데없는 코드:** 500 응답에 `if False else` 조건식을 잘못 넣었다. 테스트 전에 발견해 단순하게 고쳤다.
