- LG 드럼 설명서 검색어가 설명서 표지 시리즈 표기(`FX25*N*·FX24*N*·FX23*N*`)라 LG 고객지원 매뉴얼 검색에서 찾아지는지 확인하지 못함. 1차부터 같은 값이고 이번 변경과는 무관. 확인 방법: 매뉴얼 검색에 `FX24GNG`와 `FX25*N*`를 각각 넣어 보고 바꿀지 결정
- 로컬 axe 확인 필요 2건(서랍·전체 삭제 확인의 color-contrast): 모달 뒤 막과 겹쳐 바탕색을 못 정한 것으로 보임, 사람이 눈으로 확인(Task 8 화면 확인)
- 앞으로/뒤로로 대화 id 없는 `#chat/<모델>`에 오면 항상 새 대화(모델 카드 = 새 대화 결정의 결과). 기다리던 첫 질문의 답은 저장돼 최근 대화 카드로 볼 수 있음
- 입력창 포커스 링은 강제 색(고대비) 모드에서 알약이 아니라 textarea 둘레에만 그려짐
- 턴 순서는 저장 순서라 늦은 답이 다음 답보다 늦게 저장되면 1, 3, 2 순서가 될 수 있음
