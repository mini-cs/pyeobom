# 펴봄 디자인 가이드

- 날짜: 2026-10-28 (1일차, 계획 Task 11 Step 1)
- 기준: 기획서 4.1(C안 검색형), 4.2(소개 영역·검색창 동작), 4.3(레퍼런스 원칙)
- 규칙: 화면 코드(`public/styles.css`)는 아래 CSS 변수만 쓴다(CLAUDE.md). 새 값이 필요하면 이 문서에 먼저 토큰을 추가한다.

## 2. 색 (토큰)

방향은 "종이 설명서를 펴 본 느낌"이다. 따뜻한 미색 바탕에 흰 카드를 올리고, 강조색은 차분한 청록 하나만 쓴다. 제조사 고유 색(LG 빨강, 삼성 파랑)은 쓰지 않는다.

| 토큰 | 값 | 쓰는 곳 | 대비(배경 기준) |
|---|---|---|---|
| `--color-bg` | `#F7F5F0` | 페이지 바탕(미색) | — |
| `--color-surface` | `#FFFFFF` | 카드·검색창·모델 표시 | — |
| `--color-text` | `#1C1F23` | 본문·제목 | 흰색 위 16.5:1 |
| `--color-text-muted` | `#5B6470` | 보조 문구·남은 글자 수·하단 고지 | 흰색 위 6.0:1, 미색 위 5.5:1 |
| `--color-border` | `#E3DFD6` | 카드·입력창 테두리 | 장식용(글자 아님) |
| `--color-primary` | `#1F5E5B` | 전송 버튼·링크·포커스 테두리·근거 박스 왼쪽 선 | 흰색 위 7.5:1 |
| `--color-primary-hover` | `#174845` | 버튼을 누르거나 가리킬 때 | 흰색 위 10.2:1 |
| `--color-on-primary` | `#FFFFFF` | 전송 버튼 글자 | 청록 위 7.5:1 |
| `--color-evidence-bg` | `#EEF5F4` | 근거 박스 바탕 | 본문색 15.0:1, 보조 글자 5.4:1 |
| `--color-warning-bg` | `#FFF6E0` | 공용 가이드 경고 바탕 | — |
| `--color-warning-text` | `#7A4B00` | 공용 가이드 경고 글자 | 경고 바탕 위 6.9:1 |
| `--color-error-bg` | `#FDECEA` | 오류 안내 바탕 | — |
| `--color-error-text` | `#B3261E` | 오류 안내 글자 | 오류 바탕 위 5.7:1 |

- 글자 대비는 모두 WCAG AA(본문 4.5:1 이상)를 넘게 잡았다. 수치는 WCAG 상대 휘도 공식으로 계산했다(2026-10-28). 화면을 구현한 뒤 브라우저 개발자 도구로 다시 확인한다.
- 상태를 색만으로 구분하지 않는다. 경고와 오류에는 항상 글자 라벨을 함께 둔다("공용 콘텐츠라…", "일시적인 문제가…").
- 1차에서는 어두운 화면(다크 모드)을 지원하지 않는다.

## 3. 글꼴과 글자 크기

- 글꼴: 시스템 글꼴을 쓴다. 웹 글꼴을 내려받지 않아 첫 화면이 빠르다.
  - `--font-sans: -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif`
- 한글 줄바꿈: `word-break: keep-all`. 단어 중간에서 줄이 바뀌지 않게 한다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--text-xs` | `12px` | 하단 고지 |
| `--text-sm` | `14px` | 보조 문구, 남은 글자 수, 근거 박스 쪽수 라벨, 예시 질문 버튼 |
| `--text-md` | `16px` | 본문, **검색창**(16px 미만이면 아이폰이 입력할 때 화면을 확대한다) |
| `--text-lg` | `18px` | 답변 카드 제목, 서비스명 "펴봄" |
| `--text-xl` | `22px` | 소개 제목("세탁기·에어컨, 설명서 대신 물어보세요") |
| `--leading-body` | `1.6` | 본문 줄 간격(한글은 영문보다 넉넉하게) |
| `--leading-tight` | `1.35` | 제목 줄 간격 |
| `--weight-regular` / `--weight-bold` | `400` / `700` | 굵기는 두 단계만 |

## 5. 움직임

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--motion-collapse` | `300ms ease` | 소개 영역 접기·펼치기(기획서 4.2) |
| `--motion-fast` | `150ms ease` | 버튼 색 바뀜 |

- `@media (prefers-reduced-motion: reduce)`에서는 `transition: none`으로 바로 접는다.
- 로딩은 움직이는 그림 대신 "설명서를 펴 보는 중…" 글자와 진행 표시줄 하나로 보여 준다. 진행 표시도 동작 줄이기 설정을 따른다.

## 6. 부품별 모양 (기획서 4.1 순서)

1. **상단 줄:** 서비스명 "펴봄"(`--text-lg`, 굵게)만 둔다. 소개 영역이 접혀도 남는다.
2. **소개 영역:**
   - 제목(`--text-xl`)과 부제(`--text-md`, `--color-text-muted`)
   - 신뢰 포인트 3개("공식 설명서 근거", "근거 페이지 표시", "모르면 모른다고 해요")는 테두리만 있는 알약 모양(`--radius-pill`, `--text-sm`)이다. 누를 수 없으므로 버튼처럼 보이지 않게 그림자를 넣지 않는다.
3. **선택 모델 + "변경"** (레퍼런스 3):
   - 흰 카드 한 줄에 "LG 벽걸이 에어컨 (SQ06FA1WDS)"를 쓰고, 오른쪽 끝에 "변경" 링크(`--color-primary`)를 둔다.
   - 모델 선택 화면에는 `model_name_hint`를 보조 문구로 보여 준다.
4. **검색창:**
   - 흰 바탕, `--color-border` 테두리, `--radius-sm`, 높이 48px 이상, `--text-md`
   - 안내 문구에 예시를 넣는다(레퍼런스 3). 예: "무엇이 궁금한가요? 예) 통세척 방법, 4E 에러"
   - 남은 글자 수(`--text-sm`, muted)는 오른쪽 아래에 둔다. 50자 이하로 남으면 `--color-warning-text`로 바꾼다.
   - 전송 버튼: `--color-primary` 바탕, 흰 글자, `--tap-min` 이상. 로딩 중에는 잠그고(`disabled`) 글자를 "찾는 중…"으로 바꾼다.
5. **예시 질문 버튼:** `--radius-pill`, 흰 바탕과 테두리, `--text-sm`, 높이 `--tap-min`. 폭이 모자라면 다음 줄로 넘긴다. 가로 스크롤은 쓰지 않는다(폭 360px에서 가로 스크롤 없음).
6. **답변 카드** (레퍼런스 1):
   - 흰 카드, `--radius-md`, 테두리와 `--shadow-card`
   - 제목(`--text-lg`)과 결론 한두 문장을 먼저 쓴다. 그 아래 조치 방법을 번호 목록으로 둔다.
   - **근거 박스:** `--color-evidence-bg` 바탕에 왼쪽 3px `--color-primary` 선을 둔다.
     - 위쪽에 출처 라벨(`--text-sm`, 굵게)을 둔다. 설명서는 "사용설명서 32쪽", 가이드는 "공식 해결 가이드: 제목"이다.
     - 아래에 인용 1~2문장(150자 이내)을 둔다.
     - 에러 코드 질문이면 코드를 크게, 뜻을 [대괄호 라벨]로 붙이는 2단 표기를 쓴다(레퍼런스 2). 예: "OE" / "[배수 문제]"
   - **공용 가이드 경고:** 근거 박스 안 맨 아래에 `--color-warning-bg`와 `--color-warning-text`로 "공용 콘텐츠라 모델에 따라 다를 수 있어요"를 쓴다. 문구는 기획서 그대로다.
   - **"공식 문서 열기":** 카드 맨 아래의 글자 링크다. 새 탭으로 열고 `rel="noopener"`를 붙인다.
7. **찾지 못함:** 답변 카드와 같은 모양이고 근거 박스는 없다. "설명서에서 찾지 못했어요" 다음에 `official_url`로 가는 "공식 고객센터에서 찾아보기" 링크를 둔다. 실패가 아니라 정직한 답이므로 오류 색을 쓰지 않는다.
8. **오류:** `--color-error-bg`와 `--color-error-text`, `--radius-md`. 서버의 `message`를 그대로 보여 주고, 다음 행동("다시 시도")을 버튼으로 둔다.
9. **개인정보 안내** (`pii_masked`): 검색창 바로 아래에 `--color-warning-bg`로 한 줄 안내를 둔다.
10. **하단 고지:** `--text-xs`, muted, 가운데 정렬. "비영리 학습용 포트폴리오 · 설명서 저작권은 각 제조사"
