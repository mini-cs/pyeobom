# 안정성 테스트 기록

기획서 7장의 네 가지(이상 입력·실패·빈 화면·민감정보)를 실제로 막는지 확인한 기록이다. 자동 테스트(`pytest`)로 확인하는 항목은 테스트 이름을, 브라우저에서 확인하는 항목은 방법과 결과를 적는다.

## 화면 (Task 11, 2026-10-29)

- **확인 환경:** 로컬 `experiments/dev_server.py`(API + `public/`)에 실제 Neon·`gpt-6-luna`를 연결했다. Claude Code가 Playwright로 폭 360×740 브라우저를 띄워 확인했다.
- **캡처:** `docs/design/screens/01~06`. 화면에 나온 전화번호는 가짜 값(`010-1234-5678`)이다.

|---|---|---|

- 삼성 세탁건조기에서 예시 질문 "통세척은 어떻게 해요?"가 **찾지 못함**으로 나왔다. 설명서에는 "통세척"이 8·32·70쪽에 있는데 검색 상위 5개에 들지 않았다(검색 실패).
- 삼성에서 "에러 코드가 떴어요"(코드 없이 물음)도 찾지 못함으로 나왔다. LG 드럼과 에어컨의 예시 질문 4개는 근거가 붙어 나왔다.
